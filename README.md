I'm Smriti Ranjan, a Computer Science and Engineering student interested in backend development, Java, Spring Boot and modern AI-powered applications.

I created this portfolio to bring my work and learning journey together in one place. Instead of keeping everything in a traditional static layout, I wanted to explore a more interactive way of presenting projects and technical skills.

The website combines a 3D visual experience with a clean portfolio structure, so visitors can explore the work without losing sight of the details.

## Featured Projects

### CampusQuery AI Engine
**Java · Spring Boot · PostgreSQL · pgvector · Ollama · Docker**

An intelligent campus query engine that processes university PDF documents and provides context-grounded answers. It uses vector similarity search with PostgreSQL and pgvector, along with Ollama, to retrieve relevant information. The application also includes secured REST APIs, JWT authentication and role-based authorization.

### Expense Tracker API
**Java · Spring Boot · MySQL · Spring Data JPA**

A personal finance application for managing transactions, calculating balances and categorizing expenses. It uses a normalized relational database structure and provides REST endpoints with validation and global exception handling.

### Meal Finder App
**JavaScript · HTML5 · CSS3 · REST API**

A responsive recipe discovery application that uses TheMealDB API. It supports recipe searches, asynchronous data fetching and dynamic rendering through DOM manipulation.

## Running Locally

Want to explore the project or run it on your own machine?

You'll need Node.js 20.9 or later and npm.

**1. Clone the repository**

```bash
git clone https://github.com/hii-dims/smriti-3d-portfolio.git
```

**2. Move into the project directory**

```bash
cd smriti-3d-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

The project is organized into separate areas for the application, components, content, utilities and public assets.

- `app/` – Application routes and global styles.
- `components/` – Reusable interface and portfolio components.
- `constants/` – Portfolio content and configuration.
- `hooks/` – Reusable React hooks.
- `helpers/` – Shared helper functions.
- `animations/` – Animation-related code.
- `public/` – Static assets, images and 3D models.
- `docs/` – Project documentation.

## Deployment

The portfolio can be deployed using [Vercel](https://vercel.com/).

Import the GitHub repository into Vercel, keep the Next.js framework settings and deploy. Optional environment variables and additional setup for features such as the contact form and admin panel are documented in the `docs/` directory.
