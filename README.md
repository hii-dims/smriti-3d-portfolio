### Expense Tracker API
**Java · Spring Boot · MySQL · Spring Data JPA**

A personal finance application for managing transactions, calculating balances and categorizing expenses, with REST APIs and database integration.

### Meal Finder App
**JavaScript · HTML5 · CSS3 · REST API**

A responsive recipe discovery application using TheMealDB API, with asynchronous data fetching and dynamic recipe rendering.
